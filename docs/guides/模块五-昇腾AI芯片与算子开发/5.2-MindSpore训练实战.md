## 1. MindSpore 训练四件套

任何 MindSpore 训练脚本都由四件套组成：

| 组件 | 角色 | PyTorch 对应物 |
| --- | --- | --- |
| Dataset | 数据加载与预处理 | DataLoader + transforms |
| nn.Cell（模型） | 网络结构 | nn.Module |
| Loss / Optimizer | 损失与优化器 | torch.nn 损失 / optimizer |
| Model + 回调 | 训练循环组织 | 手写 training loop |

用 `Model` 包裹后，训练循环（前向、反向、参数更新、评估）由框架驱动，开发者通过**回调（Callback）**挂接日志、保存、早停等逻辑。

## 2. 数据集：Dataset API 与数据变换

```python
import mindspore.dataset as ds

def create_dataset(data_dir, batch_size=32):
    dataset = ds.ImageFolderDataset(data_dir)
    dataset = dataset.map(operations=[decode, resize, normalize])  # 数据变换
    dataset = dataset.batch(batch_size)                            # 组 batch
    dataset = dataset.repeat(1)                                    # epoch 数
    return dataset
```

**要点**：数据变换用 `map` 挂接；`batch` 组批；`repeat` 控制 epoch。和 PyTorch 的 `map`/`shuffle` 概念对应，但接口更「算子化」。

## 3. 模型定义：nn.Cell

```python
import mindspore as ms
from mindspore import nn

class LeNet(nn.Cell):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(1, 6, 5, pad_mode='valid')
        self.conv2 = nn.Conv2d(6, 16, 5, pad_mode='valid')
        self.fc1 = nn.Dense(16 * 5 * 5, 120)
        self.fc2 = nn.Dense(120, 84)
        self.fc3 = nn.Dense(84, 10)

    def construct(self, x):       # 注意：MindSpore 用 construct 不是 forward
        x = self.conv1(x)
        x = nn.ReLU()(x)
        x = nn.MaxPool2d(kernel_size=2, stride=2)(x)
        # ... 省略中间层
        return self.fc3(x)
```

**关键差异**：MindSpore 的模型继承 `nn.Cell`，前向函数叫 **`construct`** 而不是 `forward`——因为静态图编译时 `construct` 会被「解析成图」，PyTorch 的 `forward` 语义是直接执行。

## 4. 训练：Model.train 与回调

```python
from mindspore import Model, LossMonitor, CheckpointConfig, ModelCheckpoint

model = Model(net, loss_fn=loss_fn, optimizer=optimizer, metrics={'acc'})

callbacks = [
    LossMonitor(print_every=10),
    ModelCheckpoint(prefix='lenet', directory='./ckpt',
                    config=CheckpointConfig(save_checkpoint_steps=100)),
]

model.train(epoch=5, train_dataset=dataset, callbacks=callbacks)
```

**回调机制**是 MindSpore 训练编排的核心：`LossMonitor` 打印 loss、`ModelCheckpoint` 定时存 checkpoint、还有 `EarlyStopping`、`TimeMonitor` 等。生产训练几乎全靠回调组合。

## 5. 完整示例：LeNet 训练流程

把四件套拼起来：

```python
import mindspore as ms
from mindspore import nn
from mindspore.dataset import MnistDataset

# 1. 上下文：昇腾 + 静态图
ms.set_context(mode=ms.GRAPH_MODE, device_target='Ascend')

# 2. 数据集
train_ds = MnistDataset('MNIST').map(...).batch(32)

# 3. 模型 + 损失 + 优化器
net = LeNet()
loss_fn = nn.SoftmaxCrossEntropyWithLogits(sparse=True, reduction='mean')
optimizer = nn.Momentum(net.trainable_params(), learning_rate=0.01, momentum=0.9)

# 4. Model + train
model = Model(net, loss_fn, optimizer, metrics={'acc'})
model.train(epoch=5, train_dataset=train_ds,
            callbacks=[LossMonitor(print_every=10)])

# 5. 评估
eval_ds = MnistDataset('MNIST_test').map(...).batch(32)
model.eval(eval_ds)
```

**对比 PyTorch**：PyTorch 里手写 for 循环做梯度更新；MindSpore 里 `model.train()` 代劳，逻辑以回调形式注入。

## 6. 检查点保存与恢复

```python
# 保存（已通过 ModelCheckpoint 回调自动完成）

# 恢复
from mindspore import load_checkpoint, load_param_into_net
param_dict = load_checkpoint('./ckpt/lenet-1_1875.ckpt')
load_param_into_net(net, param_dict)
```

checkpoint 文件保存的是参数表，加载时按参数名匹配注入网络——和 PyTorch 的 `state_dict` + `load_state_dict` 思路一致。

## 7. 与 PyTorch 训练循环的对照

| 步骤 | PyTorch | MindSpore |
| --- | --- | --- |
| 模型定义 | `nn.Module` + `forward` | `nn.Cell` + `construct` |
| 数据管线 | DataLoader + transforms | Dataset + map + batch |
| 损失/优化器 | torch.nn.* / torch.optim.* | mindspore.nn.* |
| 训练循环 | 手写（或 Trainer） | `Model.train` + 回调 |
| 设备设置 | `.to('cuda')` | 上下文 `device_target='Ascend'`（默认昇腾） |
| checkpoint | `state_dict` | `CheckpointConfig` / `load_checkpoint` |

**迁移口诀**：`forward→construct`、`Module→Cell`、`手写循环→Model.train+回调`。其余概念几乎一一对应。

## 总结

- MindSpore 训练四件套：**Dataset + nn.Cell + Loss/Optimizer + Model**。
- 关键差异：`construct` 定义前向、`Model.train` 驱动训练循环、回调挂接旁路逻辑。
- 检查点保存/恢复与 PyTorch 的 state_dict 思路一致。
- 从 PyTorch 迁移 MindSpore，改的是「表达方式」，不变的是「训练原理」。
