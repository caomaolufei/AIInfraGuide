## 本章简介

本章是昇腾系列学习的起点。和 NVIDIA GPU 之于 CUDA 一样，昇腾芯片（Ascend NPU）是理解 CANN 软件栈、Ascend C 算子开发和昇腾推理优化的「地基」。

**芯片家族与演进路线**帮你建立全景认知：从主打推理的 310P，到训练旗舰 910B / 910C，再到演进中的新一代芯片，弄清楚「训练卡」和「推理卡」在硬件设计上的本质差异。

**达芬奇架构**是昇腾的心脏。我们会拆解 AI Core 内部的 AI Cube（矩阵计算）、AI Vector（向量计算）、AI Scalar（标量控制）三大计算单元，理解为什么昇腾敢于用「达芬奇」这个文艺复兴大师命名自己的架构。

**存储层次**部分梳理 HBM → L2 → AI Core 片上 Buffer 的数据通路，并与 CUDA 内存模型做对照，让你已有的 GPU 知识可以平滑迁移。

**多卡互联**介绍 HCCS 片间互连、PCIe 与 RoCE 组网，回答「8 卡怎么连」「跨节点怎么通信」这些分布式训练绕不开的问题。
